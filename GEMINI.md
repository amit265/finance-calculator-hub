# Technical Implementation

## Component Standards

*   **Logic Isolation:** Keep calculation logic in pure functions within the component or a dedicated utility file.
*   **Sync to URL:** Every input change must debounced-sync to URL search params using `next/navigation`.
*   **Responsiveness:** All charts must use `ResponsiveContainer` from Recharts.
*   **Printability:** Use `no-print` and `print:block` Tailwind classes to ensure reports look professional when printed or saved as PDF.
*   **Formatting:** Use `Intl.NumberFormat` for all currency and percentage displays.

## Shared Calculator Utilities

Create a `lib/calculator-utils.ts` for:

*   Currency formatting.
*   PDF generation logic (if beyond `window.print()`).
*   URL param parsing and serialization.
*   Shared types for calculation results.

# Content Writing Guide

To meet the 1000+ words requirement per section, follow this structure for each calculator page:

## 1. What Is This Calculator? (1000+ Words)

*   **Definition:** Clear explanation of what the tool calculates.
*   **Target Audience:** Who benefits from this specific calculation?
*   **Real-world Context:** Why does this calculation matter in the current economic climate?
*   **History/Origins:** Brief background on the financial concept.

## 2. How It Works (1000+ Words)

*   **Step-by-Step Guide:** Walkthrough of each input field.
*   **Variable Explanations:** Deep dive into what each variable (e.g., "Compounding Frequency") actually means for the user.
*   **Behind the Scenes:** High-level overview of the logic used.
*   **Assumptions:** State what the calculator assumes (e.g., constant interest rates).

## 3. Examples (500+ Words)

*   **Scenario A:** Conservative/Average case.
*   **Scenario B:** Aggressive/High-growth case.
*   **Scenario C:** "What if" case (e.g., missing a few years of contributions).

## 4. Formula Explanation (500+ Words)

*   **The Math:** Show the raw formula.
*   **Breakdown:** Explain each component of the formula in plain English.
*   **Manual Calculation:** Walk the user through a manual calculation for a simple case.

## 5. Benefits & Common Mistakes (500+ Words each)

*   **Benefits:** Clarity, goal setting, time-saving.
*   **Mistakes:** Not accounting for inflation, overestimating returns, ignoring taxes.
